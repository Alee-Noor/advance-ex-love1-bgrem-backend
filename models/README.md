# Models Directory

The BiRefNet ONNX model (`birefnet-general.onnx`, ~927 MB) is automatically downloaded during Docker image build or on first execution via Python fallback.

To download it manually:
```bash
curl -L -o models/birefnet-general.onnx https://github.com/danielgatis/rembg/releases/download/v0.0.0/BiRefNet-general-epoch_244.onnx
```
